## 📚 Références Techniques

### **Format .gw**
- **Version supportée** : GeneWeb 7.0.0+
- **Encodage** : UTF-8 (recommandé) ou ISO-8859-1
- **Structure** : Texte basé, lisible par humain et machine

### **Événements Supportés**
- **Personnels** : Naissance, décès, occupation, etc.
- **Familiaux** : Mariage, divorce, séparation, etc.
- **Personnalisés** : Événements définis par l'utilisateur

### **Extensions gwplus**
- Événements personnels (`pevt`)
- Événements familiaux (`fevt`)
- Pages étendues (`page-ext`)
- Notes de base de données (`notes-db`)
