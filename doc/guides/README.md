## 🎯 Parcours Utilisateur Recommandé

### 1. **Premier Démarrage**
1. Suivez le [guide de déploiement](./GENEWEB_DEPLOYMENT.md)
2. Testez l'accès avec le [guide d'accès à GeneWeb](./ACCES_GENEWEB.md)

### 2. **Utilisation de vos Données**
1. Comprenez le [format des fichiers .gw](./GUIDE_FICHIERS_GW.md)
2. Ajoutez vos bases généalogiques
3. Explorez l'interface GeneWeb

### 3. **Résolution de Problèmes**
- Consultez la section troubleshooting de chaque guide
- Vérifiez les logs Docker
- Utilisez les commandes de diagnostic
